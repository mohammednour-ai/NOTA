🌸 Welcome to NOTA!

AI-Powered Perfume Recommendation Platform

✅ Installation Complete! Your project files are ready.

📋 Step 1: Get Your Anthropic API Key (Required)

You need a Claude API key to power the AI recommendations:

  1. Visit console.anthropic.com
  2. Sign up or log in to your account
  3. Navigate to "API Keys" section
  4. Click "Create Key"
  5. Copy the key (starts with sk-ant-)
Get API Key →

⚙️ Step 2: Create .env File

Create a new file named .env in your project root with:

ANTHROPIC_API_KEY=sk-ant-your-key-here
PORT=3000

That's it! The other API keys are optional.

🚀 Step 3: Start the Server

In your terminal, run:

npm start

Or use the convenient startup script:

  • Windows: Double-click start.bat
  • Mac/Linux: Run ./start.sh

🌐 Step 4: Open in Browser

Navigate to:

http://localhost:3000
Open NOTA →
⚠️ Important: Never commit your .env file to version control! It's already in .gitignore.
