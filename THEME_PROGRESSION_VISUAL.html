⚙️ How It Works

  1. Q1: User selects gender → System detects choice
  2. Q2-Q30: Each question advances theme by ~3.3%
  3. Math: Progress = (Current Q / Total Q) × 100
  4. Color Mix: Neutral + (Target - Neutral) × Progress
  5. Smooth: 0.8s CSS transitions on all elements
  6. Result: Fully personalized visual experience!
