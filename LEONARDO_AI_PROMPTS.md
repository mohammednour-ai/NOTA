## 📋 Generation Workflow

### Step-by-Step Process:

1. **Go to Leonardo.ai**
   - URL: https://leonardo.ai/
   - Create free account (150 credits/day)

2. **Select "Image Generation"**
   - Click "Create New Image"

3. **For Each Image:**
   - Copy the prompt from above
   - Set the model (Phoenix/Kino/Diffusion XL)
   - Set aspect ratio
   - Paste prompt in main field
   - Paste negative prompt in negative field
   - Enable Prompt Magic & Alchemy
   - Set number to 4
   - Click "Generate"

4. **Select & Download:**
   - Review 4 generated options
   - Choose the best one
   - Click download
   - Save with specified file name

5. **Organize Files:**
   ```
   public/images/
     hero/
       hero-perfume-bg.jpg
       hero-lifestyle.jpg (optional)
     logo/
       logo-icon.png
     loading/
       loading-perfume.png

       results-bg-pattern.png
     icons/
       icon-floral.png
       icon-fresh.png
       icon-citrus.png
       icon-woody.png
       icon-oriental.png
       icon-gourmand.png
   ```

## 🔄 If Results Need Refinement

**Common Issues & Fixes:**

### Issue: Colors too dark
**Fix:** Add to prompt: "bright, light, airy, white background, high key lighting"

### Issue: Too detailed/busy
**Fix:** Add to prompt: "minimal, simple, clean, negative space, single subject"

### Issue: Not luxury enough
**Fix:** Add to prompt: "high-end, luxury, elegant, sophisticated, professional photography"

### Issue: Wrong style
**Fix:** Change model:
- Too artistic → Switch to **Phoenix**
- Need cinematic → Switch to **Kino**
- Need versatile → Use **Diffusion XL**
