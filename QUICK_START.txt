🚂 STEP 3: DEPLOY TO RAILWAY (10 MINUTES)
───────────────────────────────────────────────────────────────

A. Sign Up:
   → Go to: https://railway.app
   → Click "Login with GitHub"
   → Authorize Railway

B. Create Project:
   → Click "New Project"
   → Select "Deploy from GitHub repo"
   → Choose: mohammednour-ai/NOTA
   → Railway will start building (2-5 minutes)

C. Add Environment Variables:
   → Click your service → "Variables" tab
   → Add these THREE variables:
   
   ANTHROPIC_API_KEY = sk-ant-your-actual-key-here
   PORT = 3000
   NODE_ENV = production
   
   ⚠️  IMPORTANT: Replace with your real API key!

D. Get Railway URL:
   → Settings → Domains
   → Copy your URL (e.g., nota-production.up.railway.app)
   → Test it in browser - should work!

🌐 STEP 4: CONNECT YOUR DOMAIN (5 MINUTES)
───────────────────────────────────────────────────────────────

A. In Railway:
   → Settings → Domains → "+ Custom Domain"
   → Enter: www.nota-life.com
   → COPY the CNAME value (e.g., nota-production.up.railway.app)

B. In GoDaddy:
   → Login: https://www.godaddy.com
   → My Products → nota-life.com → DNS
   → Click "Add" record:
      • Type: CNAME
      • Name: www
      • Value: [paste Railway CNAME]
      • TTL: 600
   → Click "Save"

🆘 TROUBLESHOOTING
───────────────────────────────────────────────────────────────

❌ App won't start on Railway?
   → Check Railway logs (Deployments → View Logs)
   → Verify ANTHROPIC_API_KEY is set correctly
   → Make sure it starts with: sk-ant-

❌ Domain not working?
   → Wait longer (DNS can take 2 hours)
   → Check dnschecker.org
   → Clear browser cache / try incognito
   → Verify CNAME in GoDaddy matches Railway

❌ Git push fails?
   → Make sure you created the repo first
   → Name must be exactly: NOTA
   → Authenticate when GitHub prompts you
