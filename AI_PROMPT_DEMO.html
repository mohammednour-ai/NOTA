🎯 AI Prompt Template (What Claude Receives)

⚠️ Current Prompt: This is the EXACT prompt sent to Claude AI 
Based on the following user preferences for perfume, recommend 5 specific perfumes that would be perfect for them. Include the brand name and perfume name.

User Preferences:
{
  "1": "Female",
  "2": "18-25",
  "3": ["Daily wear", "Evening events"],
  ...
}

IMPORTANT: Consider ALL types of perfumes including:
- Celebrity fragrances (Ariana Grande, Billie Eilish, Taylor Swift, Rihanna, etc.)
- Designer brands (Chanel, Dior, YSL, Gucci, Versace, etc.)
- Popular mainstream (Victoria's Secret, Bath & Body Works, etc.)
- Niche and luxury brands (Tom Ford, Jo Malone, etc.)

For YOUNG users (18-25) or those wanting TRENDY scents, prioritize:
- Ariana Grande (Cloud, Thank U Next, Sweet Like Candy, R.E.M.)
- Billie Eilish Fragrances
- Viktor&Rolf Flowerbomb
- Marc Jacobs Daisy
- Paco Rabanne Olympea
- Lancôme Idôle
- Prada Candy

Please analyze these preferences and recommend 5 perfumes. For each perfume, provide:
1. Brand and perfume name
2. Brief description (2-3 sentences)
3. Why it matches their preferences
4. Key notes
5. Match percentage (how well it matches user preferences, 75-99%)

Format your response as a JSON array with this structure:
[
  {
    "brand": "Brand Name",
    "name": "Perfume Name",
    "description": "Description here",
    "why": "Why it matches",
    "notes": ["note1", "note2", "note3"],
    "matchPercentage": 95
  }
]

Order recommendations from highest match percentage to lowest.

Prompt Structure Analysis:

Section 1: Context
Tells Claude what to do: "recommend 5 specific perfumes"
Section 2: User Data
All 30 quiz answers in JSON format
Section 3: Perfume Types
Lists all perfume categories to consider
Section 4: Priority Brands
For young users (18-25), prioritize trendy brands
Section 5: Output Format
Specifies exact JSON structure for response
Section 6: Requirements
5 fields per perfume + match percentage
🎯 Key Logic Points:
  • Always returns 5 perfumes
  • Match percentage ranges from 75-99%
  • Results ordered by match percentage (highest first)
  • Considers user age, gender, and preferences
  • Prioritizes trendy brands for young users

🧠 Current Logic & Potential Improvements

✅ What Works Well:

  • ✅ Considers all 30 quiz answers
  • ✅ Age-appropriate recommendations
  • ✅ Budget-aware suggestions
  • ✅ Prioritizes trendy brands for young users
  • ✅ Match percentage for transparency
  • ✅ Includes reasoning ("why it matches")

💡 Potential Improvements:

  • 📊 Weighted Preferences: Give more importance to certain answers (e.g., budget, fragrance family)
  • 🎯 Exclude Dislikes: Explicitly exclude notes user said "not for me"
  • 🌍 Regional Availability: Consider if perfumes are available in user's country
  • 🔄 Diversity: Ensure recommendations span different price points and brands
  • 💰 Budget Strictness: Make budget range more strict (currently flexible)
  • 📈 Confidence Score: Add confidence level to match percentage
  • 🎨 Seasonal Weight: Give more weight to selected seasons

⚙️ Suggested Prompt Enhancements:

ADDITIONAL RULES YOU COULD ADD:

1. STRICT BUDGET COMPLIANCE:
   "Only recommend perfumes within the user's budget range. If budget is $50-$100, 
   do NOT recommend perfumes over $100."

2. EXCLUDE DISLIKES:
   "Do NOT recommend perfumes containing notes the user explicitly disliked 
   (e.g., if they selected 'Not for me' for woody notes, avoid all woody perfumes)."

3. DIVERSITY REQUIREMENT:
   "Ensure recommendations include at least 3 different brands and span different 
   price points within the budget."

4. SEASONAL PRIORITY:
   "Prioritize perfumes suitable for the seasons user selected. If they chose 
   'Spring' and 'Summer', focus on lighter, fresher scents."

5. OCCASION MATCHING:
   "If user selected specific occasions (e.g., 'Date nights', 'Work/Office'), 
   ensure each perfume is explicitly labeled as suitable for those occasions."
