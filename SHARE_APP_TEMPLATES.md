## Dynamic Variables

All templates support these dynamic variables:

- `{REFERRAL_LINK}` - User's unique referral URL
- `{SHORT_LINK}` - Shortened referral URL
- `{YOUR_NAME}` / `{USER_NAME}` - Sharing user's name
- `{FRIEND_NAME}` - Recipient's name
- `{PERSONALITY_TYPE}` - User's personality result
- `{PERFUME_NAME}` - Top matched perfume
- `{PERFUME_BRAND}` - Brand of top match
- `{MATCH_PERCENTAGE}` - Match percentage (e.g., "95")
- `{REFERRAL_CODE}` - User's referral code

## Usage in Code

```javascript
const template = templates.whatsapp.replace('{REFERRAL_LINK}', referralLink)
                                   .replace('{PERSONALITY_TYPE}', personalityType)
                                   .replace('{PERFUME_NAME}', perfumeName)
                                   .replace('{MATCH_PERCENTAGE}', matchPercentage);
```
