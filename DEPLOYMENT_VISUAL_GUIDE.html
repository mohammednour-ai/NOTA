Create GitHub Repository Action Required

First, let's get your code on GitHub so Railway can deploy it.

  1. Click the button below to create a new GitHub repository
  2. Name it: nota-life
  3. Make it Private (recommended)
  4. DO NOT check any initialization options (README, .gitignore, license)
  5. Click "Create repository"
Create GitHub Repo →
💡 Tip: Keep the GitHub page open - you'll need to copy commands from there in the next step.
2

Push Code to GitHub Action Required

Now let's upload your code to GitHub. Open PowerShell in your project folder and run these commands:

# Navigate to your project
cd d:\Lab2

# Add GitHub as remote (replace YOUR_USERNAME!)
git remote add origin https://github.com/YOUR_USERNAME/nota-life.git

# Push your code
git branch -M main
git push -u origin main
⚠️ Important: Replace YOUR_USERNAME with your actual GitHub username!

Expected result: You should see output showing files being uploaded, ending with something like "Branch 'main' set up to track remote branch 'main'"

3

Deploy to Railway Action Required

Railway will host your app. It's fast, reliable, and handles SSL automatically.

3.1 Sign Up for Railway

  1. Click the button below to go to Railway
  2. Click "Login" → "Login with GitHub"
  3. Authorize Railway to access your GitHub
Go to Railway →

3.2 Create New Project

  1. Click "New Project"
  2. Select "Deploy from GitHub repo"
  3. Choose your nota-life repository
  4. Railway will auto-detect it's a Node.js app and start building
  5. Wait 2-5 minutes for the first deployment

3.3 Add Environment Variables

Your app needs your Anthropic API key to work:

  1. Click on your service name
  2. Go to "Variables" tab
  3. Click "New Variable" and add these three:
ANTHROPIC_API_KEY=sk-ant-your-actual-key-here
PORT=3000
NODE_ENV=production
⚠️ Critical: Replace sk-ant-your-actual-key-here with your real Anthropic API key! Get it from console.anthropic.com

3.4 Get Your Railway URL

  1. Go to "Settings" tab
  2. Under "Domains" section, you'll see your Railway URL
  3. It looks like: nota-life-production.up.railway.app
  4. Click it to test - your app should be live! 🎉
4

Connect Your Domain Action Required

Now let's make your app accessible at www.nota-life.com

4.1 Add Custom Domain in Railway

  1. In Railway, stay in "Settings" → "Domains"
  2. Click "+ Custom Domain"
  3. Enter: www.nota-life.com
  4. Railway will show you a CNAME record - COPY THIS!
  5. It looks like: your-app.up.railway.app

4.2 Configure DNS in GoDaddy

  1. Click the button below to go to GoDaddy
  2. Login and go to "My Products"
  3. Find your domain and click "DNS"
  4. Click "Add" to create a new record
  5. Fill in:
    • Type: CNAME
    • Name: www
    • Value: [paste the Railway URL you copied]
    • TTL: 600 seconds
  6. Click "Save"
Go to GoDaddy →
⏳ Wait Time: DNS changes take 10 minutes to 2 hours to propagate. Usually it's ready within 1 hour. You can check progress at dnschecker.org

4.3 Optional: Root Domain Forwarding

If you want nota-life.com (without www) to work too:

  1. In GoDaddy, go to "Forwarding"
  2. Set up domain forwarding
  3. Forward nota-life.com → www.nota-life.com
  4. Use "Permanent (301)" redirect

Troubleshooting

App Won't Start on Railway

Solution:

  1. Click your service → "Deployments"
  2. Click latest deployment → "View Logs"
  3. Look for error messages (usually missing environment variables)
  4. Verify ANTHROPIC_API_KEY is set correctly

Domain Not Working

Solution:

  1. Check DNS at dnschecker.org
  2. Enter www.nota-life.com and check CNAME record
  3. If not propagated, wait longer (can take up to 48 hours)
  4. Clear browser cache or try incognito mode
  5. Verify CNAME value in GoDaddy matches Railway URL exactly

API Errors

Solution:

  1. Check your Anthropic API key is correct
  2. Verify your Anthropic account has credits
  3. Test locally first with npm start
  4. Check Railway logs for specific error messages
