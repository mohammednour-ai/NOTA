# 🎨 Leonardo.ai Quick Reference

## 🚀 Quick Start Guide

### 1. Sign Up
- Go to: https://leonardo.ai/
- Click "Sign Up" (free account)
- Get 150 free credits daily

### 2. Start Generating
- Click "Image Generation"
- Click "Create New Image"

### 3. Essential Settings
```
Model: Leonardo Phoenix
Quality: High
Resolution: 1024x1024 (or 1536x1024 for landscape)
Number: 4
Prompt Magic: ON
Alchemy: ON
```
